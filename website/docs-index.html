DataCite Metadata Toolkit

Check DataCite 4.7 records, turn them into linked data, and map them to Schema.org, Dublin Core, DCAT and Wikidata. Every DataCite term has a permanent address under https://w3id.org/tib/datacite/.

Quick start

Run these from a copy of the toolkit repository.

1. Install

pip install -r rdf-build-scripts/requirements-mappings.txt
npm install

2. Check a JSON record

npm run --silent validate:json -- record.json

Accepts a full REST API response or just its attributes.

3. Convert it to RDF and check the RDF

npm run --silent convert:rdf -- record.json > record.ttl
python3 -m pyshacl -s validation-and-conversion/shapes/datacite-4.7-r2.shacl.ttl record.ttl

Minimal record

{
  "doi": "10.1234/example-doi",
  "creators": [{ "name": "Doe, Jane", "nameType": "Personal" }],
  "titles": [{ "title": "An Example Dataset" }],
  "publisher": { "name": "Example University" },
  "publicationYear": "2025",
  "types": { "resourceTypeGeneral": "Dataset" }
}

What’s new in DataCite 4.7

Resource types

resourceTypeGeneral adds Poster and Presentation.

Related identifier types

relatedIdentifierType adds RAiD and SWHID.

Relation types

relationType adds Other.

New property

relationTypeInformation: more information about the chosen relationType, on relatedIdentifier and relatedItem.

Learn the basics

Glossary

  • JSON Schema: describes the shape of a JSON document.
  • JSON-LD: links JSON keys to web addresses (IRIs) through an @context.
  • RDF: data as statements of subject, predicate and object.
  • SHACL: a description of what valid RDF looks like, which a validator checks.
  • SKOS / JSKOS / SSSOM: formats for controlled vocabularies and mappings.
  • Crosswalk: a table of correspondences between DataCite and another vocabulary.

What a record looks like in RDF

A description becomes a node with its text and its type side by side:

<https://doi.org/10.1234/x> dcp:description [
  a dcc:Description ;
  rdf:value "Example abstract"@en ;
  dcp:descriptionType dcv:descriptionType/Abstract ] .
