DataCite Linked Data Schema

Human-readable entry point for the DataCite linked-data vocabulary, whose permanent addresses start with https://w3id.org/tib/datacite/. It provides JSON-LD and Turtle definitions for classes, properties, controlled vocabularies, contexts, and manifests used to describe DataCite metadata.

Audience: Developers, metadata engineers, tool builders Current version: DataCite 4.7, revision 2 (4.7-r2) Machine entry point: datacite-current.json

Available Versions

DataCite 4.7-r2 (current)

Revision 2 of the DataCite 4.7 modelling, with the same terms. Each repeatable element is its own node with its text in rdf:value, and creators and polygon points are numbered with schema:position. RDF written for 4.7 must be updated; the 4.7 files stay available.

Open the DataCite 4.7-r2 manifest

DataCite 4.7 (revision 1)

The first linked-data modelling of DataCite 4.7. 4.7 adds Poster and Presentation to resourceTypeGeneral, RAiD and SWHID to relatedIdentifierType, Other to relationType, and a new relationTypeInformation property.

Open the DataCite 4.7 manifest

Open the DataCite 4.6 manifest (prior version)

datacite-current.json always points at the latest version. Use it for moving targets; use the versioned manifests for reproducibility.

How To Use These Files

  • For people: browse the categories above, then open the JSON-LD files directly or use the manifest as an index.
  • For software: start from the manifest and dereference the listed URLs/files as needed.
  • For JSON-LD processing: use the context files to interpret compact JSON keys and values.
  • For schema exploration: compare a class file, a property file, and a vocabulary term file to understand the modeling pattern.

URL Patterns (Quick Reference)

  • Classes: https://w3id.org/tib/datacite/class/{Name}
  • Properties: https://w3id.org/tib/datacite/property/{name}
  • Vocabulary schemes: https://w3id.org/tib/datacite/vocab/{scheme}
  • Vocabulary terms: https://w3id.org/tib/datacite/vocab/{scheme}/{Term}
  • Contexts: https://w3id.org/tib/datacite/context/{file}.jsonld
  • Manifests: https://w3id.org/tib/datacite/manifest/datacite-{version}.json

A term address returns its JSON-LD file. Clients that send Accept: text/turtle will get Turtle once the w3id update in perma-id/w3id.org#6828 is merged.

Notes About This Namespace

Term addresses under https://w3id.org/tib/datacite/ are permanent: a term keeps its address in every release. The files themselves are served by GitHub Pages at https://tibhannover.github.io/datacite/, and w3id redirects each address there.

To know which DataCite version a term was used under, record the versioned manifest or distribution (for example manifest/datacite-4.7-r2.json); the term address alone does not say.
